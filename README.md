# sorrisorec.com

Site da Sorriso REC — filmmaker em São Paulo. HTML puro, hospedado no GitHub Pages.

## Como editar
- Tudo está em `index.html`. Procure por **EDITAR** para achar os pontos de conteúdo.
- Vídeos ficam em `videos/` (versão completa `nome.mp4` + trecho de hover `nome-loop.mp4`).
- Capas e fotos ficam em `assets/` (`.webp`).
- Para adicionar um trabalho, copie um `<article class="reel">` dentro do capítulo certo e troque `data-title`, `data-client`, `data-video`, `data-preview` e a imagem.

## Domínio
O arquivo `CNAME` aponta o site para `sorrisorec.com`.
